BMail is a free opensource python app that'll create burner emails and write the incoming emails into files.

BMail uses MailTM´s api to get free domain which he then uses for creating free burner email with random characters as the name. BMail has a function which lets the use save incoming mails into the application root directory. 

Installation:

git clone https://github.com/asiprejsajmon/BMail
python -m venv .venv
source .venv/bin/activate
pip install -m mailtm
